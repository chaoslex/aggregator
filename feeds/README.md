# Daily proxy subscription feeds

Generated daily from public proxy configurations and checked by the aggregator before publishing.

- Clash: `clash.yaml`
- sing-box: `singbox.json`
- V2Ray-compatible (Base64): `v2ray.txt`

The generated feed files are public in this repository. The source config reads a public feed from the `@TFMTProto` channel's published GitHub file; no personal GitHub token or private data is used by scheduled runs.
